`POST /v1/token/ohlcv` · **5 per item credits**

Batch twin of [Candles (OHLCV)](/endpoints/candles-ohlcv): the candles of up to 10 tokens in one call, chains mixable in the same lot. `interval`, `limit`, `quote` and `fill` are shared by the lot; `endTime`, `from` and `pools` are per token, so every series keeps its own pagination. The response is in input order: each slot is the body of the GET (`data` plus its own `count`, `oldestTime`, `newestTime`, `hasMore`, `nextEndTime`, `pools`), or `{ "error": { "code", "message" } }` for that token alone (unknown token, malformed address, `quote=usd` on a chain without USD history). A bad item never costs you the rest of the lot.

<Note>An unknown `interval` or a lot of more than 10 items is refused with `400` for the whole call (it is a shared option). Everything else is judged per item.</Note>

<RequestExample>
```bash cURL
curl -X POST 'https://api.serialized.xyz/v1/token/ohlcv' \
  -H 'Authorization: YOUR_API_KEY' -H 'Content-Type: application/json' \
  -d '{"items": [{"chain": "evm:8453", "address": "0x4ed4e862860bed51a9570b96d89af5e1b0efefed"}, {"chain": "solana", "address": "DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263", "endTime": 1788976800}], "interval": "1h", "limit": 2}'
```
</RequestExample>
