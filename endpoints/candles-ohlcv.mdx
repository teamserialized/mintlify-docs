`GET /v1/token/ohlcv` · **5 credits**

Chart-ready candles from 1s to 1M. **Token-wide by default**: we resolve the pool we price the token from and, for a token that graduated from a bonding curve, stitch its curve history onto the current pool so the series is continuous. Pass `pools=` to aggregate an explicit set instead (≤50). Wick-outlier clamping and candle connecting are applied server-side. On Base, the forming candle folds preconfirmed (flashblocks) swaps ~2.5s before block commit.

<Note>An unknown token returns `404`. Prices are native-quoted by default (`meta.quote: "native"`); on Solana pass `quote=usd` for USD candles, otherwise multiply by the native USD price.</Note>

<Note>`meta.nextEndTime` appears when a page ends early on a very deep scan - pass it as the next `endTime` to keep paging. Otherwise page with `oldestTime - 1`. Historical pages are immutable and cached, so pagination is fast and deterministic.</Note>

<RequestExample>
```bash cURL
curl 'https://api.serialized.xyz/v1/token/ohlcv?chain=evm:8453&address=0x4ed4e862860bed51a9570b96d89af5e1b0efefed&interval=1h&limit=24' \
  -H 'Authorization: YOUR_API_KEY'
```
</RequestExample>
