`GET /v1/meta/factories`

Launchpad and factory keys of the registry: `factories` lists every key, `byChain` the keys the `factories=` filter of [`/v1/pulse`](/endpoints/pulse) accepts for each chain. EVM and Solana. Free.

<Note>Keys are accepted in any form on input (`PUMPFUN`, `pump.fun`, the indexer's `PUMP_FUN`); the response carries the canonical form. A key listed under a chain always produces a feed on that chain. On Solana the list also carries the trading venues (`PUMPSWAP`, `RAYDIUM`, `ORCA`, `METEORA`) the filter accepts there, next to the launchpads. The example is abridged: the live response lists every registry key and every chain.</Note>

<RequestExample>
```bash cURL
curl 'https://api.serialized.xyz/v1/meta/factories' \
  -H 'Authorization: YOUR_API_KEY'
```
</RequestExample>
