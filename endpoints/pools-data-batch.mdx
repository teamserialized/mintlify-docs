`POST /v1/pools/data` · **1 credit**

The batch twin of [Market Data](/endpoints/market-data): poll up to 100 markets - across chains - in one request instead of a fan-out of single calls. Each item carries the same shape as `/v1/pool/data`; the response array is in input order, and an unknown market slots in as `null`. Billed per market in the call.

<Note>`circulatingSupply` is `null` on the batch (it comes from a slower upstream that would stall a fan-poll); fetch it per market on `/v1/pool/data` when you need it.</Note>

<Note>`meta.count` echoes the number of markets in the request (the per-market billing count).</Note>

<RequestExample>
```bash cURL
curl -X POST 'https://api.serialized.xyz/v1/pools/data' -H 'Authorization: YOUR_API_KEY' -H 'Content-Type: application/json' -d '{"markets":[{"chain":"evm:8453","address":"0x0ca6485b7e9cf814a3fd09d81672b07323535b64"},{"chain":"solana","address":"58oQChx4yWmvKdwLLZzBi4ChoCc2fqCUWBkwMihLYQo2"}],"windows":"1h,24h"}'
```
</RequestExample>
