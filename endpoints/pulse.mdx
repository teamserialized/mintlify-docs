`GET /v1/pulse` · **1 credit**

Axiom-style launchpad lifecycle columns: `new` (created under 24h), `bonding` (active curves, sorted by bonding %), `graduated` (migrated or virtually-graduated, last 7 days). ~90 launchpads tracked natively across 18 EVM chains, bonding thresholds per factory.

<ParamField query="view" type="string" required>
  new | bonding | graduated Example: `bonding`
</ParamField>

<ParamField query="chains" type="string" required>
  CSV of chain ids (≤8). Example: `evm:8453`
</ParamField>

<ParamField query="limit" type="integer">
  1-100, default 30.
</ParamField>

<Note>`bondingProgress` is consistent with the token endpoint - same factory registry, same thresholds.</Note>

<Note>`graduatedAt` uses the authoritative migration event, not the pool creation time.</Note>

<Note>chains=solana serves the Pump.fun / Raydium LaunchLab / Meteora DBC lifecycles with the same views (new, bonding, graduated).</Note>

<RequestExample>
```bash cURL (EVM)
curl 'https://api.serialized.trade/v1/pulse?view=bonding&chains=evm:8453' \
  -H 'Authorization: YOUR_API_KEY'
```
```bash cURL (Solana)
curl 'https://api.serialized.trade/v1/pulse?view=bonding&chains=solana' -H 'Authorization: YOUR_API_KEY'
```
</RequestExample>
