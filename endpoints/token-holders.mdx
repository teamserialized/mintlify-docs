`GET /v1/token/holders` · **2 credits**

Top holders with position size, share of supply, full PnL (realized + unrealized), buy/sell volumes, behavioral labels and named entities (exchanges, funds - the "Coinbase" signal). EVM and Solana.

<ParamField query="chain" type="string" required>
  Public chain id - `evm:<id>` or `solana`. Example: `evm:8453`
</ParamField>

<ParamField query="address" type="string" required>
  Token address. Example: `0x4ed4e862860bed51a9570b96d89af5e1b0efefed`
</ParamField>

<ParamField query="limit" type="integer">
  1-100, default 50. Example: `5`
</ParamField>

<Note>`meta.totalHolders` carries the token's full holder count.</Note>

<Note>`entityName` identifies known wallets (exchanges, funds); `labels` carry behavioral tags (whale, bundler, sniper).</Note>

<RequestExample>
```bash cURL
curl 'https://api.serialized.xyz/v1/token/holders?chain=evm:8453&address=0x4ed4e862860bed51a9570b96d89af5e1b0efefed&limit=5' -H 'Authorization: YOUR_API_KEY'
```
</RequestExample>
