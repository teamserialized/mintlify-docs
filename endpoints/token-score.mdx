`GET /v1/token/score` · **10 credits** · access is provisioned per API key

One number to gate a trade, and the full reasoning behind it. The score starts at 100 and applies 18 weighted checks (liquidity depth, LP burn/lock, holder concentration with pools and exchange custody excluded, sniper/bundler activity, authorities, taxes, contract safety, token age, smart-money conviction), a global adjustment for tier-1 CEX listings, and two market-condition reductions (freshly launched pools, collapse from the 30-day high). A fatal flaw skips everything and returns 0 with an explicit kill code.

- **`securityScore`** - the 0-100 result, integer.
- **`tier`** - risk bucket derived from the score.
- **`killed` / `killReason`** - a fatal flaw zeroes the score with a stable machine code (for example `HARD_KILL:HONEYPOT`, `HARD_KILL:SELL_TAX`, `HARD_KILL:TOP10_CONCENTRATION`, `HARD_KILL:ATH_DRAWDOWN`).
- **`securityScoreDetails`** - the complete breakdown: every check with its delta and metadata, the inputs the engine saw, hard floors, the CEX multiplier and the tier-1 exchanges found, raw and final score, both global reductions, `computedAt`. The shape is a drop-in for the `securityScoreDetails` object your integration already parses.

Scores are computed on request from live data and cached for up to 30 seconds, so a rug reflects on the first uncached read: the score collapses through the kill logic rather than fading.

<Note>Available as a batch: `POST /v1/token/score` with `items[]` of `{chain, address}`, billed per item. The per-call item cap is provisioned with your key.</Note>

<Note>Supported on every chain we index, EVM and Solana alike, with the same response shape. `chain` takes a public chain id: `solana`, `evm:1`, `evm:56`, `evm:8453`, `evm:42161`, and the rest of the catalog from `/v1/meta/chains`.</Note>

<RequestExample>
```bash cURL
curl 'https://api.serialized.xyz/v1/token/score?chain=solana&address=DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263' \
  -H 'Authorization: YOUR_API_KEY'
```

```bash Batch
curl -X POST 'https://api.serialized.xyz/v1/token/score' \
  -H 'Authorization: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"items":[
    {"chain":"solana","address":"DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263"},
    {"chain":"evm:8453","address":"0x4ed4e862860bed51a9570b96d89af5e1b0efefed"}
  ]}'
```
</RequestExample>
