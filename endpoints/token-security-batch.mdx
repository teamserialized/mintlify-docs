`POST /v1/token/security` · **10 credits**

The batch twin of [Token Security](/endpoints/token-security) - screen a whole watchlist in a single call. The response array is in input order with per-item `{error}` slots, and every item carries the same union shape (authorities, concentration, launch quality, liquidity safety, taxes, dexPaid). Mixed EVM and Solana in one call is fine.

<ParamField body="items" type="array" required>
  Up to 500 of `{chain, address}`. Response array is in input order with per-item `{error}` slots. Billed per item. Example: `[{"chain":"solana","address":"DezXAZ…"}]`
</ParamField>

<Note>Authority tri-state: `mintRevoked: true` = renounced (safe), `false` = active, `null` = unknown. USDC keeps both authorities active (Circle can mint & freeze - expected for a regulated stablecoin, a red flag on a memecoin); BONK has both revoked.</Note>

<Note>Batch: up to 500 Solana items; EVM capped at 100 items per call (per-token holder scans).</Note>

<RequestExample>
```bash cURL
curl -X POST 'https://api.serialized.xyz/v1/token/security' -H 'Authorization: YOUR_API_KEY' -H 'Content-Type: application/json' -d '{"items":[{"chain":"solana","address":"DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263"},{"chain":"evm:8453","address":"0x4ed4e862860bed51a9570b96d89af5e1b0efefed"}]}'
```
</RequestExample>
