`POST /v1/token/security` · **10 credits**

Per-family security fields. Solana: mint/freeze authority state (on-chain truth). EVM: holders count, top-10 concentration (CEX-custody excluded), dev/snipers/bundlers holdings %, token burn %, buy/sell/transfer tax (on-chain simulation), dexPaid. null always means unknown, never a fake zero.

<ParamField body="items" type="array" required>
  Up to 500 of `{chain, address}`. Response array is in input order with per-item `{error}` slots. Billed per item. Example: `[{"chain":"solana","address":"DezXAZ…"}]`
</ParamField>

<Note>BONK: both authorities revoked (safe). USDC: both ACTIVE (Circle can mint & freeze - expected for a stablecoin, a red flag on a memecoin).</Note>

<RequestExample>
```bash cURL
curl -X POST 'https://api.serialized.xyz/v1/token/security' -H 'Authorization: YOUR_API_KEY' -H 'Content-Type: application/json' -d '{"items":[{"chain":"solana","address":"DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263"},{"chain":"solana","address":"EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"}]}'
```
</RequestExample>
