`GET /v1/token/security` · **10 credits**

Per-family security fields. Solana: mint/freeze authority state (on-chain truth). EVM: holders count, top-10 concentration (CEX-custody excluded), dev/snipers/bundlers holdings %, token burn %, buy/sell/transfer tax (on-chain simulation), dexPaid. null always means unknown, never a fake zero.

<ParamField query="chain" type="string" required>
  Public chain id. `solana` for now; EVM ships with the LP burn/lock indexing (explicit 400 until then, never silent nulls). Example: `solana`
</ParamField>

<ParamField query="address" type="string" required>
  Token mint (base58, case-sensitive). Example: `DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263`
</ParamField>

<Note>Batch: up to 500 Solana items; EVM capped at 100 items per call (per-token holder scans).</Note>

<RequestExample>
```bash cURL
curl 'https://api.serialized.xyz/v1/token/security?chain=solana&address=DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263' \
  -H 'Authorization: YOUR_API_KEY'
```
</RequestExample>
