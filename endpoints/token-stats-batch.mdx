`POST /v1/token/stats` · **1 per token credit**

Batch twin: the windowed stats of up to 25 `{chain, address}` tokens in one call, EVM and Solana mixed freely. The response comes back `200` in input order, one slot per token: `{ data }`, exactly the body of [`GET /v1/token/stats`](/endpoints/token-stats-windowed) for that token, or `{ error: { code, message } }` for that token alone (unknown token, malformed address, a pool that is not on the token), never `null`. One bad token never costs you the rest of the lot. Billed per token.

`windows` is shared by the whole call (an unknown window is a `400` on the call). `pools` is per token: omit it for token-wide stats across every pool of that token, or pass a CSV of up to 50 pool addresses to scope that token to those markets, exactly as on the single GET.

<Note>A slot's `data` is exactly what `GET /v1/token/stats` returns for that token with the same `windows` and `pools`: one block per window with volume, buy/sell counts and volumes, `txns` and `priceChangePct`, plus the organic counters on Solana; see that page for the fields.</Note>

<RequestExample>
```bash cURL
curl -X POST 'https://api.serialized.xyz/v1/token/stats' \
  -H 'Authorization: YOUR_API_KEY' -H 'Content-Type: application/json' \
  -d '{"items":[{"chain":"evm:8453","address":"0x4ed4e862860bed51a9570b96d89af5e1b0efefed"},{"chain":"solana","address":"DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263","pools":"5zpyutJu9ee6jFymDGoK7F6S5Kczqtc9FomP3ueKuyA9"},{"chain":"evm:8453","address":"0x00000000000000000000000000000000deadbeef"}],"windows":"1h,24h"}'
```
</RequestExample>
