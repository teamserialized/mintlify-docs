`GET /v1/token/stats` · **1 credit**

Windowed volume, buy/sell counts and volumes, transactions and price change - 5m/1h/6h/24h in one call.

<ParamField query="chain" type="string" required>
  Public chain id - `evm:<id>` or `solana`. Example: `evm:8453`
</ParamField>

<ParamField query="address" type="string" required>
  Token address. Example: `0x4ed4e862860bed51a9570b96d89af5e1b0efefed`
</ParamField>

<ParamField query="pools" type="string">
  CSV of pool addresses (≤50) to scope the stats to specific markets. **Omit for token-wide stats across every pool** - the default, and what a single token figure should be. Every pool passed must belong to the token, or the request is rejected with 400.
</ParamField>

<ParamField query="windows" type="string">
  CSV of `5m`|`1h`|`6h`|`24h`. Default: all four.
</ParamField>

<Note>The `24h` window here is the exact same figure as `stats24h` on [`/v1/token`](/endpoints/token-details) - one 24h number across the whole product.</Note>

<Note>`txns` is the exact count of transactions in the window. `buys`/`sells` and `buyVolumeNative`/`sellVolumeNative` split flow by direction. `priceChangePct` is the move across the window: the latest price against the price the token had one window-length ago - the last close before the window opened. `null` when the window carries no priced trades.</Note>

<RequestExample>
```bash cURL (EVM, token-wide)
curl 'https://api.serialized.xyz/v1/token/stats?chain=evm:8453&address=0x4ed4e862860bed51a9570b96d89af5e1b0efefed' -H 'Authorization: YOUR_API_KEY'
```
```bash cURL (Solana, token-wide)
curl 'https://api.serialized.xyz/v1/token/stats?chain=solana&address=DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263' -H 'Authorization: YOUR_API_KEY'
```
```bash cURL (explicit pools)
curl 'https://api.serialized.xyz/v1/token/stats?chain=evm:8453&address=0x4ed4e862860bed51a9570b96d89af5e1b0efefed&pools=0x0ca6485b7e9cf814a3fd09d81672b07323535b64&windows=1h,24h' -H 'Authorization: YOUR_API_KEY'
```
</RequestExample>
