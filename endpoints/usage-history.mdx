`GET /v1/usage/history`

Time series of the calling key's requests and credits over the last `days` days, bucketed at `15m`, `1h`, `6h` or `1d`: the graph of a usage dashboard. Free: never billed, and still reachable when the monthly credit allowance is exhausted. A key only ever sees its own usage.

<ParamField query="days" type="integer">
  1 to 90. Default 30. Example: `7`
</ParamField>

<ParamField query="bucket" type="string">
  `15m`, `1h`, `6h` or `1d` (default). A bucket too fine for the range (more than about 2,200 points) is refused with `400`: pick a coarser one. Example: `1d`
</ParamField>

<Note>Each point is `{ t, requests, credits }`; `t` is the bucket start in unix seconds. Buckets without traffic are absent from the series.</Note>

<RequestExample>
```bash cURL
curl 'https://api.serialized.xyz/v1/usage/history?days=7&bucket=1d' \
  -H 'Authorization: YOUR_API_KEY'
```
</RequestExample>
