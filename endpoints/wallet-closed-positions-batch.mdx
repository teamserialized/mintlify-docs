`POST /v1/wallet/closed-positions` · **2 per wallet credits**

Batch twin: up to 20 wallets per call, response array in input order. Each slot is `{ data, hasMore, oldestAt }`, the body of the single GET for that wallet, or `{ error }` when that wallet failed, so one wallet never fails the others. `limit`, `offset` and `sort` apply to every wallet of the call. Billed per wallet.

<Note>A slot's `data`, `hasMore` and `oldestAt` are exactly what `GET /v1/wallet/closed-positions` returns for that wallet with the same options; see that page for the row fields.</Note>

<RequestExample>
```bash cURL
curl -X POST 'https://api.serialized.xyz/v1/wallet/closed-positions' \\
  -H 'Authorization: YOUR_API_KEY' -H 'Content-Type: application/json' \\
  -d '{"items":[{"wallet":"0xd13da05b9288ba4961973110594bd0fe3428791f","chain":"evm:8453"},{"wallet":"GuhieZDx6nwJV14WjeUQH2ted6CGPKoGCCTaPSPNgG2E","chain":"solana"}],"limit":1,"sort":"pnl"}'
```
</RequestExample>
