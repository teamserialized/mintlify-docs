`POST /v1/wallet/profile` · **1 per item credit**

Batch twin: up to 100 addresses per call, response array in input order. Each slot is `{ data }` where `data` is the body of the single GET (`{ profile, linkedWallets }`), the same slot shape as every other batch endpoint. A wallet without a known identity comes back as `{ data: { profile: null, linkedWallets: [] } }` (identities are harvested continuously - retry later, never assume permanent).

<RequestExample>
```bash cURL
curl -X POST 'https://api.serialized.xyz/v1/wallet/profile' \
  -H 'Authorization: YOUR_API_KEY' -H 'Content-Type: application/json' \
  -d '{"items":[{"address":"0xd8da6bf26964af9d7eed9e03e53415d37aa96045"},{"address":"GuhieZDx6nwJV14WjeUQH2ted6CGPKoGCCTaPSPNgG2E"}]}'
```
</RequestExample>
