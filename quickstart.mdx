Every endpoint page in this doc has an interactive playground pre-filled with a working example: open one and hit Send. It runs against the demo server, no key needed. This page is the same first call, from your own terminal or code.

## 1. Grab a key

The playground needs no key. Your own code does: API keys are issued in conversation, [talk to us](/support) and you will have one in minutes. Paste it in place of `YOUR_API_KEY` below.

## 2. Make your first call

Full token snapshot for DEGEN on Base:

<CodeGroup>
```bash cURL
curl 'https://api.serialized.xyz/v1/token?chain=evm:8453&address=0x4ed4e862860bed51a9570b96d89af5e1b0efefed' \
  -H 'Authorization: YOUR_API_KEY'
```
```typescript TypeScript
const res = await fetch(
  'https://api.serialized.xyz/v1/token?chain=evm:8453&address=0x4ed4e862860bed51a9570b96d89af5e1b0efefed',
  { headers: { Authorization: 'YOUR_API_KEY' } },
);
const { data } = await res.json();
console.log(data.symbol, data.priceUsd, data.stats24h.volumeUsd);
```
```python Python
import requests

res = requests.get(
    "https://api.serialized.xyz/v1/token",
    params={"chain": "evm:8453", "address": "0x4ed4e862860bed51a9570b96d89af5e1b0efefed"},
    headers={"Authorization": "YOUR_API_KEY"},
)
data = res.json()["data"]
print(data["symbol"], data["priceUsd"], data["stats24h"]["volumeUsd"])
```
</CodeGroup>

## 3. Read the response

Every response is the same envelope: `{ data, meta }`, camelCase fields, millisecond timestamps, `null` meaning unknown (never a fabricated value). Trimmed here:

```json
{
  "data": {
    "chain": "evm:8453",
    "address": "0x4ed4e862860bed51a9570b96d89af5e1b0efefed",
    "name": "Degen",
    "symbol": "DEGEN",
    "priceNative": "0.00000054747124708872",
    "priceUsd": 0.0010292322577456162,
    "marketCapUsd": 37389232.09806793,
    "liquidityUsd": 239386.56038744663,
    "pool": { "address": "0x0ca6485b7e9cf814a3fd09d81672b07323535b64", "type": "UNISWAP_V3" },
    "stats24h": { "volumeUsd": 23448.59872596349, "buys": 176, "sells": 5 }
  },
  "meta": { "asOf": 1786724319903 }
}
```

The same call works on any [supported chain](/supported-chains): swap `chain=evm:8453` for `solana` and pass a base58 address.
