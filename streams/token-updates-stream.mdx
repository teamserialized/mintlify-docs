`WS channel: token-updates`

Live refresh of the mutable Token Details fields - price, market cap, liquidity, bonding progress, 24h stats. Throttled to at most one event per second per token; fields you already parse from `/v1/token`.

<ParamField body="chain" type="string" required>
  Public chain id - `evm:<id>` or `solana`. Example: `solana`
</ParamField>

<ParamField body="address" type="string" required>
  Token address. Example: `CBZq5ycLcr6mnYvjFTPuYSuhgS3ujsiTrT4sqatBpump`
</ParamField>

<Note>The refresh runs server-side through the same engine as [`/v1/token`](/endpoints/token-details), so `stats24h` carries the identical fields and numbers as the REST snapshot - re-parse events with the code you already wrote.</Note>

## Close codes

| Code | Meaning |
|---|---|
| `4401` | Auth - key missing, invalid, or revoked. Live connections are dropped the moment a key is revoked. |
| `4402` | Monthly credit quota exhausted (the WebSocket mirror of REST `402`). |
| `1008` | Policy - subscription limits, flooding, or a blocked socket. |
| `1001` | Idle timeout - no `ping` within the keepalive window. |
